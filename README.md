# 🌶️ SS Spices Company Website

### *Bringing Authentic Indian Flavours to Your Kitchen*

Welcome to the **SS Spices Company Website**! This project is a responsive website designed to showcase Indian spices and provide customers with an easy way to explore products and enquire about purchases.

## 🌐 Live Website

**Visit Website:** [SS Spices Company](https://tanishkbansal24.github.io/SSSPices_WebSite/index.html)

**GitHub Repository:** [SSSpices_WebSite](https://github.com/TanishkBansal24/SSSPices_WebSite.git)

## 📌 About the Project

SS Spices Company is a spice business website created to present authentic Indian spices through an attractive, user-friendly, and responsive design.

The website focuses on product presentation, traditional Indian flavours, and a convenient browsing experience for customers.

## ✨ Features

* 🏠 **Home Page** – Introduces the SS Spices brand.
* 🌿 **Products Page** – Showcases spices and available products.
* 📖 **About Us Page** – Shares information about the company.
* 📞 **Contact Us Page** – Helps visitors connect with the business.
* 📱 **Responsive Design** – Adapts to mobile, tablet, laptop, and desktop screens.
* 🎨 **Spice-Inspired Theme** – Uses warm colours inspired by Indian spices.
* 🛒 **Purchase Enquiry** – Provides a convenient way for customers to enquire about products through WhatsApp, where configured.

## 🛠️ Technologies Used

| Technology           | Purpose                                      |

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/TanishkBansal24/SSSPices_WebSite.git
   ```

2. Open the project folder:

   ```bash
   cd SSSPices_WebSite
   ```

3. Open `index.html` in your web browser.

4. Explore the website and navigate through its pages.

No build tools are required for a basic HTML and CSS website.
